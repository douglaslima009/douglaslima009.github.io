ASSUMINDO A LIDERANÇA

Hoje oficializamos a entrega de uma solução customizada para um de nossos clientes corporativos (NDA) na Bionic Productions. Este projeto foi um marco pessoal para mim, pois foi a primeira vez que atuei como Engenheiro de Software Líder.

CÓDIGO E GESTÃO

Desenvolver a lógica central em React Native e manter os serviços do Firebase rodando, aprendendo a coordenar a equipe, gerenciar o backlog de sprints e garantir que ninguém estava perdendo tempo com problemas que não seriam usados na versão final.
